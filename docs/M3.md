# M3 — Delivery, the Writer and the Lab

M3 gives the DM one documented control token per line — a *delivery* — chosen at the API
boundary before a job is created, plus a resident-LLM pencil for spelling and speech pacing.
It does not touch the render path: `worker.plan` and `render_line` still see plain text,
just with a token already sitting in it. Binding interfaces: `docs/M3-contracts.md`;
rationale: `docs/REBUILD.md` §3, §4 and §5. The rule that governs this milestone: identity
outranks expressiveness, so a delivery ships only after it is measured, never on a hunch.

## What is where

| path | role |
|---|---|
| `app/delivery.py` | `SPICES`, `apply`, `resolve`, `available` — pure text, no GPU |
| `app/llm.py`, `app/api/write.py` | the Writer: `fix` (spelling + speech pacing), `/api/fix`, `/api/deliveries` |
| `scripts/arm_spice.py` | the Lab: measures a spice against the golden set and arms it |
| `web/app.js`, `web/ui.css` | delivery pill and pencil button on the improv bar |

## Arming a spice

A spice ships **off**. `scripts/arm_spice.py` renders the voice's golden lines twice in the
same run — bare, then with the spice's token attached after the first word — and compares
median speaker similarity, so the comparison is never against a stale calibration:

```bash
bag python -m scripts.arm_spice --voice bag --spice vzdych smiech
```

Prints a table (`spice, n, bare, spiced, drop, min, verdict`). A spice is promoted only
when the median drop is at most 0.02 and no take in the run — bare or spiced — fell below
`voice.gate["strict"]`; `krik` and anything on `voice.banned_tokens` are refused outright, no
matter how well they measure. Nothing is written without `--apply`:

```bash
bag python -m scripts.arm_spice --voice bag --spice vzdych --apply
```

which writes into `voice.yaml`:

```yaml
armed_spices:
  vzdych: {sim_drop: 0.011, min_sim: 0.918, n: 20, armed_at: "2026-09-04T10:03:00+00:00"}
```

Re-running with `--apply` re-measures: newest measurement wins, whether that arms a spice or
drops one that no longer clears the bar, and only the `MAX_ARMED` (3) smallest drops survive.
Omit `--spice` to test every candidate in one run. Locking a new reference clip clears
`armed_spices` — a new clip is a new voice, unproven again until it is re-measured.

## What the DM sees

The improv bar gains a delivery pill left of the SK/EN pills, reading "normálne" for bare.
Its popover lists every spice for the active voice: armed ones are selectable, unarmed ones
sit greyed with "neoverené v Labe" — visible, so the mechanism is never a secret, but unusable
until the Lab clears it. Choosing one is per voice and resets to bare when the voice changes.
The pencil button, right of the input, sends the typed line to the Writer for spelling and
speech pacing only — it never adds a delivery token itself and it never speaks by itself.
`Ctrl+Enter` fixes, then speaks; plain `Enter` always speaks exactly what's in the box,
spice and all.
