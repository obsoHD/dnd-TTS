# M1 — Voice lock, CLI only

M1 turns the Bag reference clip into a *locked, calibrated voice* and proves the pipeline
`canon -> synth (N takes) -> gate -> master -> store` on the box from a CLI. No web UI and
no API yet (`app/main.py` arrives in M2). Binding interfaces: `docs/M1-contracts.md`;
rationale: `docs/REBUILD.md` §1, §2, §6.

## What is where

| path | role |
|---|---|
| `docker/app.Dockerfile`, `docker/compose.yml` | the `app` image (python 3.12-slim, ffmpeg, CPU torch, resemblyzer) beside the unchanged `tts` service |
| `requirements.txt` | app deps; resemblyzer is added `--no-deps` in the Dockerfile (its metadata wants the source-only `webrtcvad`) |
| `configs/tokens.json` | every Higgs control token, grouped: `{"categories": {"emotion": [...], "style": [...], "sfx": [...], "prosody": [...]}}`; literal form `<\|category:name\|>` |
| `scripts/verify_tokens.py` | diffs `tokens.json` against the cookbook inside the running `bag-tts` image |
| `data/voices/bag/voice.yaml` | Bag seed: sampler, uncalibrated gate, master (Energy 65), banned tokens, persona, fillers, f0 band |
| `tests/golden/bag/lines.json` | 30 Slovak bank lines across all 8 categories, used by `calibrate` and `golden` |
| `app/*`, `scripts/bag_cli.py`, `tests/unit/*` | modules, CLI and unit tests exactly as the contract lists them |

## Running on the box

Everything runs inside the `app` container on the workstation. The checkout lives at
`~/dnd-tts`, so the compose volumes `${HOME}/dnd-tts/{refs,data,cache}` are the checkout's
own `refs/`, `data/`, `cache/` directories: the committed `data/voices/bag/voice.yaml` is
already `/data/voices/bag/voice.yaml` inside the container, and renders (`*.wav`) stay
untracked via `.gitignore`.

```bash
cd ~/dnd-tts
docker compose -f docker/compose.yml up -d tts        # GPU 1, host :8010; wait for /health
docker compose -f docker/compose.yml build app
alias bag='docker compose -f docker/compose.yml run --rm app'
```

Do **not** `up` the `app` service in M1: its `CMD` starts the M2 API and would restart-loop.
Use `run --rm` for one-shot commands; host networking means `BAG_TTS_URL=http://127.0.0.1:8010`
reaches the TTS. Files the container creates under `data/` are root-owned; run
`sudo chown -R "$USER" ~/dnd-tts/data` before committing calibration results.

### 1. Verify the token list

```bash
bag python -m scripts.verify_tokens      # 0 = matches the cookbook, 1 = differs, 2 = could not read it
```

### 2. Lock the reference (once, and again after any change of the clip)

The TTS may only read clips under `/refs` (mounted read-only into `tts`, read-write into
`app`), and `voice.yaml` points it at `ref_tts_path: /refs/bag/ref.wav`. The gate embeds the
copy the app keeps at `/data/voices/bag/ref.wav`. Both must be the same bytes.

```bash
mkdir -p ~/dnd-tts/refs/bag
cp ~/dnd-tts/refs/bag_ref.wav ~/dnd-tts/refs/bag/ref.wav
bag python -c "
from pathlib import Path
from app.voices import load_voice, lock_reference
v = load_voice('bag')
v = lock_reference('bag', Path('/refs/bag/ref.wav'), v.ref_transcript)
print('version', v.version, 'sha256', v.ref_sha256)"
cmp ~/dnd-tts/data/voices/bag/ref.wav ~/dnd-tts/refs/bag/ref.wav \
  || cp ~/dnd-tts/data/voices/bag/ref.wav ~/dnd-tts/refs/bag/ref.wav
```

`lock_reference` converts to mono 24 kHz 16-bit, trims head/tail at -42 dBFS, peaks at
-3 dBFS, caps at 30 s, applies no EQ, records the sha256 and bumps `version`. The closing
`cmp || cp` makes the TTS clone from exactly the bytes the gate embeds: if conversion changed
anything, the locked file replaces the copy under `/refs`. Never edit `ref.wav` by hand
afterwards; a sha mismatch refuses to render until you re-lock.

### 3. Render a line

```bash
bag python -m scripts.bag_cli render --voice bag --text "Ten nie." --out /data/ten_nie.wav
```

Prints `render_id`, `seed`, `sim`, `cer` and per-stage timings. `--take N` re-rolls with the
next seed block (what Regenerate does in M2). Files land in `/data/renders/bag/<render_id>.raw.wav`
(the accepted raw take) and `<render_id>.<master_version>.wav` (mastered).

### 4. Pick the golden seed

```bash
bag python -m scripts.bag_cli audition --voice bag --seeds 0-9 --lines 10
```

Listen to `~/dnd-tts/data/audition/bag/seed<k>_<i>.wav`; choose the seed whose 10 lines are
all "the same person" and set `golden_seed` in `data/voices/bag/voice.yaml`.

### 5. Calibrate

```bash
bag python -m scripts.bag_cli calibrate --voice bag --lines tests/golden/bag/lines.json
```

30 lines x 3 takes -> SIM `baseline` (median) and `p10`, `strict = max(baseline - 0.04, p10)`,
`loose = baseline - 0.08`, and the fixed `master.gain_db` that puts the set's median loudness
at -18 LUFS; all written back to `voice.yaml` with `calibrated_at`.

### 6. Golden run

```bash
bag python -m scripts.bag_cli golden --voice bag
```

Renders `tests/golden/bag/lines.json` and asserts per line: SIM >= `strict`, CER <= 0.15, word
ratio 0.75–1.25, F0 median inside `f0_band`, loudness within ±2 LU of -18, 0.12–0.35 s per
syllable. Prints a table and exits non-zero on any failure.

## Unit tests (no GPU, no network)

```bash
python -m pip install pytest pyyaml numpy requests pedalboard pyloudnorm librosa
python -m pytest tests/unit -q
```

torch and resemblyzer are not needed locally: `app/gate.py` imports them lazily and the tests
mock them.

## Acceptance checklist (REBUILD.md §8, M1)

- [ ] `calibrate` writes the gate thresholds (`baseline`, `p10`, `strict`, `loose`, `calibrated_at`) and `master.gain_db` into `voice.yaml`
- [ ] the user picks a golden seed and judges the 10 audition lines "the same person"
- [ ] `golden` passes 30/30: SIM strict, CER, F0 band, loudness, duration
- [ ] p95 cache-miss render (2 takes + gate + master) <= 3.0 s on the box — e.g. 20 `render` calls with distinct `--text`, read the printed timings
- [ ] `master()` is byte-identical on repeated identical input (unit test plus one `render` repeated on the box)
- [ ] whisper stopped mid-run yields `verified=false` with unchanged seeds (stop lifeos whisper, re-run `render`, compare `seed`)
- [ ] blind A/B of 10 pairs vs the pre-director build: the user prefers or ties on >= 8 (render the legacy pairs before M2 deletes `server/`)
- [ ] the image has no torchaudio/parselmouth (enforced at `docker build` by the import check in `docker/app.Dockerfile`)

## Notes for the other modules

- `banned_tokens` in `voice.yaml` are the literal token strings (`<|style:shouting|>`), the
  same form `canonicalize` meets in the text; allowed tokens are built from `tokens.json` as
  `<|category:name|>`.
- `gate.*` thresholds are `0.0` and `calibrated_at: null` until `calibrate` runs, so an
  uncalibrated voice still renders and auditions (every take passes SIM).
- `ref_sha256: ""` means "not locked"; `lock_reference` fills it and bumps `version`.
- `ref_tts_path` is the reference as the TTS container sees it; the caller passes it straight
  into `tts_client.synth(ref_path=...)`.
